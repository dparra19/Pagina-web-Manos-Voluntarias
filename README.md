# Manos Voluntarias · propuesta de web

Sitio estático (HTML + CSS, sin dependencias) para presentar a los socios.

## Cómo verlo
Abre `index.html` en el navegador.

## Cómo publicarlo en GitHub Pages
1. Crea un repositorio y sube todos los archivos de esta carpeta.
2. En *Settings → Pages*, elige la rama `main` y la carpeta `/ (root)`.
3. En unos minutos tendrás la web en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Cómo editar
- Estilos y colores: `style.css` (el verde corporativo es `--green`).
- Las páginas se generan con `bash build.sh`. Edita el texto en `build.sh` y vuelve a ejecutarlo, o edita los `.html` directamente.

## Pendiente de completar (busca los corchetes `[ ]`)

- Fotos, mapa, historia, documentos de transparencia, email y WhatsApp.
